## Research references

Entries added on 2026-11-26 were retrieved and checked with Scite: each record exists and carried no retraction or correction notice on that date, and each figure quoted below was matched to the paper's own text. They are preprints unless a venue is given.

- Alonso, P., Yovine, S., & Braberman, V. A. (2026). *TDAD: Test-driven agentic development: Reducing code regressions in AI coding agents via graph-based impact analysis*. arXiv. Telling an agent which tests cover a change cut regressions from 6.08% to 1.82%, while procedural test-driven instructions without that context raised them to 9.94%. The map delivers test links and check commands as facts and adds no procedure. [DOI](https://doi.org/10.48550/arxiv.2603.17973)
- Bhola, I., Krishnan, A., Kurmala, S., & NS, M. (2026). *Code isn't memory: A structural codebase index inside a coding agent*. arXiv. A leak-audited, model-controlled ablation of a structural index built once per repository. Its cross-harness check found no regression against an agentic search baseline on resolve or localization, at no cost penalty. It informs importing once and measuring the index against the existing preview. [DOI](https://doi.org/10.48550/arxiv.2606.22417)
- Bouchard, D. (2026). *Is escalation worth it? On the depth of LLM cascades*. arXiv. A lightweight router that chooses before generation exceeded the best cascade policy on four of five datasets, mainly by avoiding the cheap model's wasted generation. Routes are chosen at planning time, and other models are tried only when a provider fails. [DOI](https://doi.org/10.48550/arxiv.2605.06350)
- Cemri, M., Pan, M. Z., Yang, S., Agrawal, L. A., Chopra, B., Tiwari, R., Keutzer, K., Parameswaran, A., Klein, D., Ramchandran, K., Zaharia, M., Gonzalez, J. E., & Stoica, I. (2025). *Why do multi-agent LLM systems fail?* arXiv. A study of failures in multi-agent systems. It informs keeping workers scoped, giving each a written work order, and reporting overlapping and out-of-scope changes from the harness. [DOI](https://doi.org/10.48550/arxiv.2503.13657)
- Chen, Z., Tang, R., Deng, G., Wu, F., Wu, J., Jiang, Z., Prasanna, V., Cohan, A., & Wang, X. (2025). LocAgent: Graph-guided LLM agents for code localization. *Proceedings of the 63rd Annual Meeting of the Association for Computational Linguistics (Volume 1: Long Papers)*. Graph search over a code graph for localization informs the definition, use, and test links in the map's evidence. [DOI](https://doi.org/10.18653/v1/2025.acl-long.426)
- Cherny-Shahar, T., & Yehudai, A. (2026). *Repository Intelligence Graph: Deterministic architectural map for LLM code assistants*. arXiv. A deterministic map of build and test structure with evidence improved mean accuracy by 12.2% and reduced completion time by 53.9% across eight repositories and three agents. The import records each check command with the file and line that declares it. [DOI](https://doi.org/10.48550/arxiv.2601.10112)
- Du, Y., Tian, M., Ronanki, S., Rongali, S., Bodapati, S., Galstyan, A., Wells, A., Schwartz, R., Huerta, E. A., & Peng, H. (2025). *Context length alone hurts LLM performance despite perfect retrieval*. arXiv. Performance fell by 13.9% to 85% as input grew, even when every relevant fact could be retrieved. The selection has a fixed budget and is never padded with weak matches. [DOI](https://doi.org/10.48550/arxiv.2510.05381)
- Fallahpour, A., Idehpour, P., Kothapalli, V., Mounier, N., Wu, S., Pardis, S., & Leskovec, J. (2026). *Memorilla: Latent semantic memory for LLMs*. arXiv. The module reads every stored document embedding and always contributes the same number of memory tokens. The authors report that its union with retrieval answers more than either alone. The repository map keeps the persistent store and the fixed, slot-structured readout and makes each slot emit source text. [DOI](https://doi.org/10.48550/arxiv.2610.21375)
- Feng, Z., Zhang, R., Yang, Y., & Xie, P. (2026). *The missing complement: State-conditioned minimal sufficient evidence for coding agents*. arXiv. Selecting a jointly sufficient set of four to eight intact source units within 6,144 tokens informs choosing units as a set across slots and keeping each unit whole. [DOI](https://doi.org/10.48550/arxiv.2609.20050)
- Gloaguen, T., Mündler, N., Müller, M. N., Raychev, V., & Vechev, M. (2026). *Evaluating AGENTS.md: Are repository-level context files helpful for coding agents?* arXiv. In the tested settings, context files increased inference cost without a statistically significant task success gain. Evaluate short project guidance on okbrain’s tasks. [DOI](https://doi.org/10.48550/arXiv.2602.11988)
- Han, T., Zhang, Y., Song, W., Fang, C., Chen, Z., Sun, Y., & Hu, L. (2026). *SWE-Skills-Bench: Do agent skills actually help in real-world software engineering?* arXiv. Of 49 skills, 39 produced no pass-rate improvement, and the average gain was 1.2%. Imported skills and recorded lessons start on trial and are measured before they are delivered to every request. [DOI](https://doi.org/10.48550/arxiv.2603.15401)
- Jayraj, P., Goyal, P., & Goyal, N. (2026). *Tree navigation without LLM summaries: A matched-cost study of hierarchical retrieval for long-document QA*. arXiv. The main benefit of summary trees can come from navigation rather than from generated summary content. The map's package lines are for navigation, and what is sent as evidence is source. [DOI](https://doi.org/10.48550/arxiv.2610.06902)
- Jones, W., Bruce, H., & Dumais, S. (2001). Keeping found things found on the web. *Proceedings of the Tenth International Conference on Information and Knowledge Management*, 119–126. The study informs the connection between capture, notes about relevance, and re-finding. [DOI](https://doi.org/10.1145/502585.502607)
- Kim, Y., Gu, K., Park, C., Park, C., Schmidgall, S., Heydari, A. A., Yan, Y., Zhang, Z., Zhuang, Y., Liu, Y., Malhotra, M., Liang, P. P., Park, H. W., Yang, Y., Xu, X., Du, Y., Patel, S., Althoff, T., McDuff, D., & Liu, X. (2025). *Towards a science of scaling agent systems*. arXiv. Every multi-agent variant degraded sequential reasoning tasks by 39% to 70%, and independent agents amplified errors 17.2 times against 4.4 times under centralized coordination. A plan uses one worker unless the evidence falls in separate areas, and one coordinator combines the reports. [DOI](https://doi.org/10.48550/arxiv.2512.08296)
- Li, H., Li, H., Jiang, Z., & Lou, Y. (2026). *When sub-agents work in parallel: The promises and pitfalls of dynamic concurrency in long-horizon coding tasks*. arXiv. Concurrency did not consistently raise success and used 1.41 to 3.31 times the tokens of sequential execution. The plan preview states the estimated tokens of all planned calls, and fan-out is the exception. [DOI](https://doi.org/10.48550/arxiv.2610.10263)
- Li, H., Zhang, Y., Guo, Z., Wang, C., Tang, S., Zhang, Q. E., Chen, Y., Qi, B., Ye, P., Bai, L., Wang, Z., & Hu, S. (2026). *LLMRouterBench: A massive benchmark and unified framework for LLM routing*. arXiv. Several recent routing methods, including a commercial router, did not outperform the best single model. Every routed choice records the fixed first model beside it, and learning can be turned off. [DOI](https://doi.org/10.48550/arxiv.2601.07206)
- Liu, N. F., Lin, K., Hewitt, J., Paranjape, A., Bevilacqua, M., Petroni, F., & Liang, P. (2024). Lost in the middle: How language models use long contexts. *Transactions of the Association for Computational Linguistics, 12*, 157–173. Information placement and distractor volume belong in context evaluation. [DOI](https://doi.org/10.1162/tacl_a_00638)
- Liu, T., Xu, C., & McAuley, J. (2023). *RepoBench: Benchmarking repository-level code auto-completion systems*. arXiv. The benchmark separates snippet retrieval, completion, and end-to-end evaluation. [DOI](https://doi.org/10.48550/arXiv.2306.03091)
- Nakayashiki, K. (2026). *Lessons from luck: Do LLM-written lessons carry chance into an agent's next decision?* arXiv. A lesson written after a chance failure led readers to the worse choice in 11.6% of next runs, against 0.4% for controls. Task vocabulary is attached to a declaration only after a second accepted request, and no lesson is written by a model. [DOI](https://doi.org/10.48550/arxiv.2610.33029)
- Pham, H., Nguyen, C. D. T., Le Van, D., Srey, P., & Luu, A. T. (2026). *Reliable memory from unstable growth: Curating self-written agent playbooks with randomized experiments*. arXiv. Self-written playbooks were unstable across runs, and the agent's own judgement missed the harm. Measuring blocks of lessons in a randomized experiment and serving what helps informs the trial of each skill and lesson. [DOI](https://doi.org/10.48550/arxiv.2610.18427)
- Saha, S. (2026). *Delivery, not storage: Cue-anchored working memory as a harness property for coding agents*. arXiv. An agent with a seeded store, connected tools, and explicit guidance made no memory calls in 114 turns. The harness decides which facts and lessons apply and delivers them with the selection. [DOI](https://doi.org/10.48550/arxiv.2607.20972)
- Sepidband, M., Pham, H. V., & Hemmati, H. (2026). *On the role of fault localization context for LLM-based program repair*. arXiv. More localization context did not uniformly improve repair, and file-level localization gave the largest return. The budget goes first to the units with the strongest evidence. [DOI](https://doi.org/10.48550/arxiv.2604.05481)
- Vallecillos Ruiz, F., Bouzenia, I., Pradel, M., & Moonen, L. (2026). *The hidden costs of forgetting: A study of trajectory deletion in software engineering agents*. arXiv. Under caching-aware pricing, every evaluated deletion configuration had a higher estimated cost than the uncompressed baseline. okbrain bounds what a request selects at admission and leaves admitted history intact. [DOI](https://doi.org/10.48550/arxiv.2610.35496)
- Vogel, M., Meyer-Eschenbach, F., Kohler, S., Grünewald, E., & Balzer, F. (2026). *Codebase-Memory: Tree-sitter-based knowledge graphs for LLM code exploration via MCP*. arXiv. A persistent code graph reached 83% answer quality against 92% for file exploration at ten times fewer tokens. It informs keeping a persistent structural index and the exact-name path for the detail an index loses. [DOI](https://doi.org/10.48550/arxiv.2603.27277)
- Wang, Y., Cheng, H., Li, X., Hao, Y., Ramesh, H. N., Jung, D., Tang, H., Wang, K., Zhou, C., Wu, Q., Yao, W., Grama, A. Y., Banburski, A., Peng, B., Lanier, J., & Gao, J. (2026). *Certified long-horizon code agent evolution via validation-gated skill optimization*. arXiv. Gating each change on validation informs the replay check that every parameter update must pass before it is kept. [DOI](https://doi.org/10.48550/arxiv.2609.32990)
- Xue, J., Wang, Y., Li, X., Mo, L., Sengupta, A., Garg, S., Ramanathan, M. K., & Kim, M. (2026). *AECP: Artifact-exclusive communication protocol for multi-agent code generation*. arXiv. Communicating only through artifacts improved test pass rate by 10.6% over a single agent and by 28.2% over teams that exchange free-form messages. Workers exchange nothing while they run, and the coordinator reads only their written reports. [DOI](https://doi.org/10.48550/arxiv.2610.06481)
- Zhang, F., Chen, B., Zhang, Y., Keung, J., Liu, J., Zan, D., Mao, Y., Lou, J.-G., & Chen, W. (2023). - Zhang, Q., Hu, C., Upasani, S., Ma, B., Hong, F., Kamanuru, V., Rainton, J., Wu, C., Ji, M., Li, H., Thakker, U., Zou, J., & Olukotun, K.
