# Zettelkasten

A method of knowledge work built on **linked atomic notes**: each note holds
one idea, and value emerges from the links between them rather than from any
hierarchy.

Modern digital descendants include [Evergreen notes](/notes/evergreen-notes.md);
tools like [okbrain](/projects/okbrain.md) store such notes as an
[Open Knowledge Format](/references/open-knowledge-format.md) bundle.
