# okbrain

A personal brain that stores everything as an
[Open Knowledge Format](/references/open-knowledge-format.md) bundle —
markdown plus YAML frontmatter in git — with a derived, always-rebuildable
index for search and graph queries. Built to hold methods like
[Zettelkasten](/notes/zettelkasten.md) without locking the notes into a tool.
